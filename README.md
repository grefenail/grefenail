## 🧠 About This Repository

This project presents a **comparative study between Convolutional Neural Networks (CNNs)** and **Vision Transformers (ViTs)** for **object detection** and **instance segmentation**.  
We benchmarked **Faster R-CNN**, **Mask R-CNN**, and **DETR** on the **COCO 2017** and **Fashionpedia** datasets, evaluating their **mAP**, **Recall**, and training behavior.

The repository includes:
- 📘 Reproducible **Jupyter notebooks** for training and fine-tuning models  
- ⚙️ Scripts for **data preprocessing, visualization, and metrics tracking**  
- 📊 A **Streamlit dashboard** for interactive result exploration  

This study was developed as part of the **Machine Learning (WS 24/25)** course at the **University of Technology Nuremberg (UTN)**.
